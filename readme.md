Fonctionnalités
1) ajouter une tâche
2) afficher les tâches
3) rechercher une tâche
4) quitter le programme

Étapes réalisées
1) création du fichier main.py
2) création du menu principal
3) ajout de la fonctionnalité d'ajout de tâches
4) création du fichier readme.md

Exécution
1) ouvrir le dossier du projet dans VS Code
2) ouvrir le fichier main.py.
3) cliquer sur "Run Python File"
4) utiliser le menu dans le terminal
